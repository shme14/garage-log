Garage Log - Drive spike

How to run this test (tap to hide)

Goal: find out if the app can read and write one shared Google Drive folder from the partner's iPhone. Run Mode A first. Only if Mode A fails, run Mode B.

  • Mode A = scope drive.file + the folder Picker.
  • Mode B = scope drive, finds the folder by name (no Picker).

After each part, tap "Copy log" and paste the log back to Claude.

Owner (Android), Mode A

  1. Paste the API key into the "API key" box (it is remembered on this device).
  2. Mode = drive.file. Tap 1. Sign in and approve.
  3. Tap 2. Create folder "Garage Log".
  4. Tap 5. Write my file.
  5. In the normal Google Drive app or website: share the "Garage Log" folder with the partner as Editor. Tell the partner it is ready.

Partner (iPhone)

  1. In Safari, open this page. Enter the API key. Mode = drive.file.
  2. Tap 1. Sign in (use the partner's own Google account) and approve.
  3. Tap 4. Pick folder (Picker), open the "Shared with me" tab, select "Garage Log", and confirm.
  4. Tap 6. List & read all. The owner's file should show and be readable.
  5. Tap 5. Write my file, then 6. List & read all again. Copy the log.
  6. Repeat all of the above from the home-screen icon: in Safari tap Share, then "Add to Home Screen", close Safari, open the new icon. The page should say "installed app: yes". Note whether it asks you to sign in again.

Owner again

  1. Tap 6. List & read all. The partner's file should appear and be readable. Copy the log.

Mode B (only if Mode A failed)

  1. Change Mode to drive (this signs you out). Sign in again on each device.
  2. Use 3. Find folder (drive mode) instead of the Picker, then 6. List & read all and 5. Write my file. Same order: owner, partner (Safari, then home-screen icon), owner.
